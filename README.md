# 🔑 KeyShift

> macOS 快捷键学习辅助浮窗 · 专为 Windows 转 Mac 用户设计

---

## 这是什么？

KeyShift 是一个常驻 macOS 菜单栏的半透明浮窗工具。

如果你从 Windows 换到了 Mac，却总是不自觉地按 `Ctrl+V`、用 `Enter` 试图打开文件、或者找不到锁屏快捷键——KeyShift 就是为你做的。

- **速查面板**：随时瞥一眼，查 Mac 快捷键是什么
- **测试模式**：随意按键，立即告诉你这个键在 Mac 上是什么意思
- **Windows 陷阱纠错**：按了 Windows 习惯的错误键？立刻高亮提示 Mac 的正确姿势
- **不打扰设计**：半透明浮窗，不抢焦点，你仍然在控制其他软件

---

## 使用方法

1. 安装后，菜单栏出现 🔑 图标
2. 点击图标展开速查面板
3. 点击「进入测试模式」，随意按组合键查看含义
4. 按 `Esc` 或再次点击图标隐藏浮窗
